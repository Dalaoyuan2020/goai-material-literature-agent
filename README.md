# SolidEvidence：材料科学文献驱动的科学发现智能体

本仓库用于参加 **GOAI 2026 AI for Research**，对应方向三“材料科学文献驱动的科学发现智能体”。项目目标是构建可追溯、可核验、可复现的材料科学文献调研 Agent，并在结构化证据的约束下识别 Research Gap。

与普通搜索、通用问答或普通 RAG 不同，SolidEvidence 将系统输出区分为：

- **文献事实 F**：能够回溯至原文页码、段落、表格或图注；
- **跨文献推论 I**：由多条可比证据综合得到，并显式记录适用条件；
- **待验证假设 H**：来自证据缺口或冲突，必须给出可证伪假设和验证方法。

## 当前成果

### 1. Baseline 初赛方案

Baseline 选取“高镍层状氧化物正极—硫化物固态电解质界面稳定性”为案例，重点分析涂层、堆叠压力、截止电压、温度、面载量和循环制度差异造成的跨文献不可比与结论冲突。

方案采用“确定性工作流编排 + 多角色 Agent + 专业工具 + 结构化知识库 + 人工复核”的混合架构，覆盖任务拆解、检索、筛选、PDF 解析、材料知识抽取、实体规范化、跨文献融合、冲突检测、Research Gap 生成、证据核验与报告生成。

已完成一次 Sciverse 最小真实案例验证：返回 10 条候选片段，成功读取前 5 条上下文，全文读取错误为 0。人工初筛得到 E1—E4 证据记录，并形成一条仍待扩展全文和材料专家核验的假设 H1；该结果只证明数据源连通、语义召回和证据定位可行，不代表完成系统性能评测。

成果入口见 [`submissions/baseline/`](submissions/baseline/README.md)。

### 2. 工程原型与搜索实验

仓库同时保留材料关系图谱、规则化候选生成、迭代搜索、审计式 LLM 接口和可视化实验。当前工程案例使用超导材料家族验证搜索循环与证据审计能力，与 Baseline 方案中的硫化物全固态电池科学问题属于不同验证案例。

截至 2026-08-12，仓库状态记录为：81 条核心证据边、53 篇唯一 DOI、94 个核心材料、210 条 MatKG 弱证据边；四个单案例与全家族验收通过，测试 17/17 通过。真实 LLM API 成功调用为 0，相关输出明确标记为 `heuristic_fallback_llm_unreachable`，不得解读为真实模型效果。

## 安全、证据与合规

- 仓库不保存 Sciverse Token、LLM Key、个人联系方式或未公开数据；密钥仅通过本地 `.env` 或环境变量注入。
- API 返回内容和第三方全文应遵守账号权限、平台条款、版权与数据许可证；公开成果只保留允许发布的标识、摘要、派生结构和去敏记录。
- 文献事实、跨文献推论和待验证假设必须显式区分；未完成全文核验或专家确认的内容不得表述为确定结论。
- 赛事提交前须由团队复核科学判断、工具许可证、数据来源及 AI 辅助规定。
