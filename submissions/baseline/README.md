# Baseline 初赛成果说明

## 项目名称

**SolidEvidence：面向硫化物全固态锂电池界面稳定性的证据驱动文献调研 Agent**

## 参赛方向

GOAI 2026 AI for Research · 方向三“材料科学文献驱动的科学发现智能体” · 基本任务“文献调研 Agent”。

## 文件清单

- [`材料科学文献调研Agent_算法赛初赛方案.docx`](材料科学文献调研Agent_算法赛初赛方案.docx)：使用赛事原始 Word 模板完成的初赛方案，包含科学问题理解、技术方案、方法路线、真实小案例、复现与开放计划及团队介绍。
- [`Sciverse_小案例证据清单.json`](Sciverse_小案例证据清单.json)：Sciverse 最小案例的去敏检索记录，保存查询配置、候选片段、`doc_id`、页码、偏移和读取上下文，不包含 API Token。

## 本轮完成情况

- 研究对象：高镍层状氧化物正极与硫化物固态电解质界面；
- 核心问题：实验条件差异、证据缺口和跨文献冲突；
- 架构选择：确定性工作流编排 + 多角色 Agent；
- 数据状态：完成 Sciverse 真实最小 API 连通与证据定位验证，尚未下载 Sci-Base；
- 案例结果：返回 10 条候选片段，前 5 条上下文读取成功，`content_errors=[]`；
- 人工初筛：整理 E1—E4 证据记录，并提出待验证假设 H1；
- 实验状态：尚未完成人工金标集、对比实验或系统性能评测，文档中以“初步可行性验证方案”如实表述。

## 关键边界

1. 检索命中不等于科学事实，只有完成全文读取并能定位原文的记录才可进入事实层；
2. H1 仍是方向性假设，不能宣称为已确认 Research Gap；
3. E3、E4 尚需扩展全文，E2 的电解质化学与测试条件仍需交叉核验；
4. JSON 用于复核检索过程，不可直接替代正式参考文献表；
5. Sciverse Token、LLM Key 和个人联系方式均不得提交到仓库。
